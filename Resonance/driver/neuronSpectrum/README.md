# Neuron-Spectrum

Updated: 2026-09-25.

Neurosoft WinUSB binding 2.0.0.9, 2023-01-31. Uses Windows' built-in WinUSB driver.
`Install.bat` requires administrator rights. For Neuron-Spectrum; Resonance eStim
and Neuro-MS require the separate EzUSB package. Disconnect those families during installation.

Reference: [Neurosoft documentation](https://neurosoft.com/en/documents).
