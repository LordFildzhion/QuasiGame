# Movicom / FTDI

Updated: 2026-09-25.

FTDI D2XX + virtual COM driver 2.12.36.20, 2024-10-28. Windows 10/11 x64.
`Install.bat` installs both USB and serial-port packages; administrator rights required.
Preserve `amd64` and `i386` beside the INFs. The i386 DLL supports 32-bit applications on x64 Windows.

Reference: [FTDI drivers](https://ftdichip.com/drivers/d2xx-drivers/). License terms are in the INFs.
