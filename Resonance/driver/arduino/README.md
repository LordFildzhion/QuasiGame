# Arduino / Genuino

Updated: 2026-09-25.

USB serial bindings: Arduino 1.2.3.0, Arduino.org 1.1.1.0, Genuino 1.0.3.0.
Uses Windows' built-in USB serial driver. `Install.bat` requires administrator rights.
CH340/CH341 boards use the separate `ch340` package; FTDI boards use `movicom`.

Reference: [Arduino software](https://www.arduino.cc/en/software/).
