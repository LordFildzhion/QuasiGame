# Operator manuals

Audience: people operating the equipment and applications. The illustrated Word documents
remain Word documents, with their embedded images and original content unchanged. They are
not required reading for coding agents and are not converted to machine-oriented Markdown.

- [Recorder manual](manuals/recorder.docx)
- [Stimulus presentation manual](manuals/stimulus-presentation.docx)
- [NVX-52 driver manual](manuals/nvx-52.docx)
- [NVX-136 driver manual](manuals/nvx-136.docx)
- [Neuron-Spectrum-65 driver manual](manuals/neuron-spectrum-65.docx)

These publications retain their original dates and illustrated interfaces. The August editions
can show the previous Qt 5 interface and `R:\dist\msvc64` layout. Check the edition and rig before
using a historical path or pictured setting. The current distribution is `R:\dist`, with `bin`
directly under it. This documentation reorganization did not revise or revalidate the manuals.

[Legacy TEP operator notes](legacy-tep.md) retain the former Markdown operator material,
including later TepSound/viewer additions, as a scoped historical publication.

Developers should start at the [coding task index](../README.md) and use current source-linked
component contracts. Future operator-facing revisions should update the Word publication itself.
