## Processing modes and lifecycle

| Mode | Signal needed | Calibration pair needed | Output |
|---|---|---|---|
| `presentationOnly=true` | no | no | Cue/stage/trigger only; analysis worker stopped |
| SOUND disabled | yes | no | Ordinary preprocessing, epochs, MEP, rejection; no repair/training/clean |
| SOUND enabled | yes | yes | Calibration/repair/clean/average/classification |

Idle→armed→running⇄paused, Stop→idle. Armed is an active analysis state: hand-fired pulses can build MEP/epochs and warm SOUND without presenting cues. Pause stops presentation but **does not starve continuous analysis**. State-entry behavior is shared by UI, config client and CLI. Stop writes the derived epoch file and closes presentation resources; preserve analysis stream ownership across planned changes.

## Calibration and geometry contract

Montage and lead-field asset are a **matched pair**. Same labels/order is insufficient: the two lab64-channel CED files have different positions. `Calibration::checkPairing` refuses mismatch. Preserve asset/provenance pairing.

SOUND uses the lead field through its Gram matrix. The shipped MATLAB-generated random dipole model is not regenerated by substituting another language's RNG; tests establish Gram-route equivalence.

Epoch workRate must divide input rate; outputRate must divide workRate. Guard must cover the FIR context; refuse insufficient guard rather than pad plausible data. Do not change scientific settings merely to reproduce a historical performance figure. Current defaults/accepted ranges are defined by parameter setup and validation, not the old “recommended” table.

## Pipeline order and invariants

The representative default path is:

1. Raw hardware trigger edge, before any alteration.
2. Continuous narrow artifact blank/interpolation and join smoothing.
3. Continuous stateful IIR preprocessing.
4. Cut guarded epoch, then integer reduction to workRate.
5. Scale EEG toµV; per-epoch TMS-tail interpolation.
6. Anti-alias FIR fused with output decimation and guard trim.
7. Baseline and common-average reference.
8. Take **unrepaired training data** when SOUND enabled.
9. Spatial repair/optional ICA → preprocessed epoch.
10. Apply current SOUND operator → cleaned epoch; update appropriate average/classifier.

MEP is measured in its separate work-rate path; avoid applying EEG display/SOUND settings to EMG implicitly. Raw trigger detection and artifact-before-filter order are non-negotiable. Preserve continuous filter state and meaningful gap/rejection reporting.

Temporal operators identical per channel commute with fixed spatial matrices, allowing spatial work **after trim**. The fused FIR computes only retained valid outputs with identical arithmetic; it is not a different filter. Band-limit before each subsampling step; disabled/inadequate lowpass may alias.

**Never reconstruct training data by pseudo-inverting a previous repair.** Repair is rank-deficient; information is gone and repeated correction destabilized the noise model. Store unrepaired training data, derive repair afresh and apply it to the same block. This also lets the detector unflag recovered electrodes. Repairing an averaged training block is equivalent to averaging repaired epochs and avoids growing repeated work.

Exclude repaired channels from reference selection: their residuals are artificially small because they carry no independent signal. Protected channels, badness thresholds and maxBadFrac are analysis choices; C5/C6 were intentionally not automatically protected in the documented montage. Flag caps and nonconvergence remain visible.

## Epoch store, averaging and live changes

Warmup epochs can exist without a clean trace. `clean` is silent until a valid model; do not publish fabricated zero clean output. Keep rejected epochs and rejection reasons, not only accepted data.

Average uses the **newest usable contributing geometry**, skipping incompatible epoch shapes. It must not freeze on the oldest geometry or draw an old-size array against new axes. After a window change, withhold incompatible average publication until new data exists; expose `averageWithheld`.

`accepted` counts non-rejected stored epochs, including warmup; `contributing` counts what actually entered the average. `anchorRejected` is the existing wire name for skipped unusable newest anchors. `recleaned` distinguishes epochs cleaned with the current operator from stored online results. Do not tidy these wire names into compatibility breaks.

`averageSource=online` means what was published at the time; current-model average can re-clean stored data. `keepGuarded` controls whether changing earlier preprocessing settings can rederive old epochs; without guarded inputs, those edits affect future epochs. A model/window change must not pretend all history was reprocessed.

## Trigger timing and interlocks

Epoch anchors come from the amplifier's **recorded trigger edge**, not the presentation swap or command send time. Keep dueRtc/frame, sentRtc, board residual and physical edge separate. A serial board removes some scheduling uncertainty but USB/dispatch still affect when its command reaches it.

Input triggerChannel0 resolves to last channel in this pipeline's parameter convention; do not reinterpret it as zero-based first-channel indexing. Bit/edge polarity is rig-specific. The documented TMS output is about120µs and NVX136 level-samples:1kHz can miss most pulses. The historical25kHz recommendation applies to that capture path; it is not a generic proof for another amplifier.

tmsStatus is in the **input** parameter group. Gate by named metadata lanes; selected missing/stale/nonfinite required telemetry refuses pulses. No selected telemetry means no gate. Charged readiness must reflect settled capacitor after intensity changes. A scheduled skipped trial and refused manual pulse are distinct event categories; notArmed manual refusal does not necessarily increment trial-skip count.

Read triggerOutReady with backend: ready1/backendNone means no output configured, not evidence of a working physical wire. Full backend enum now includes UDP as in [presentation](stimulus-presentation.md). Changes to shared stage/wire shutdown must be tested in both services.

## Stream and file contract

- `epochs`: Float64 preprocessed **pre-SOUND** epoch, including repaired/reference/baseline processing when enabled; MEP in first auxiliary slot.
- `clean`: same geometry after SOUND, empty during warmup.
- `average`: same declared geometry, emitted only when valid.
- `events`: Message JSONv1 epoch/model/cap/cue/pulse/trigger-state/session/run records.
- `status`: Float64 **42** named lanes at nominal2Hz; authoritative order in statuschannels.hpp.

Status names/order are **append-only**. Append matching values in publishStatus too; short value lists can pad plausible zeros. Recorder refuses live incompatible width; offline readers should resolve metadata names, not hard-code columns.

Derived HDF file (separate from recorder's raw stream file):

| Dataset | Meaning |
|---|---|
| `epochs` | Flattened float32 **SOUND-cleaned** epochs, geometry/rate/window/source attributes |
| `preproc` | Matching pre-SOUND form; not raw amplifier data |
| timestamps, labels, rejected, peak_uV, model_id, latency_ms | One per epoch |
| mep/amplitude_mV, onset_ms, baseline_rms_mV | MEP measurements |
| sound/operator, sigmas, convergence | Last model plus reference/train-count/condition attributes |
| channels/labels, badness, flag, incoherence, dominant | Last cap report |

The live stream called epochs and the file dataset called epochs have **different processing stages**; preserve the stored content attributes and inspect them on analysis. Legacy tepService file epochs is another different stage.

## Classifier and attribution constraints

Two-class shrinkage LDA uses configured channel/time-bin features, trace source and retained per-class trials. Geometry/source changes invalidate incompatible features/model use; class-name changes clear the window. Unknown third labels are unlabelled, never coerced into a class.

All pulses in one cue interval share a **cross-validation group**. Use per-marker groups even for consecutive identical labels. Fit class means/shrinkage/weights inside each fold; a training score or sibling-leaking split is not held-out accuracy. Subject, condition, session, feature definition, shrinkage and training trials travel with model files. Missing CV is null, not0%.

RTC is nanoseconds; attribution/perception/cue gates are milliseconds and convert by1,000,000 exactly once. Label modes distinguish newest prior marker from perception-delayed attribution. No prior marker is not an arbitrary current label when clocks disagree; use [labelattribution.hpp](../../src/tepSoundService/labelattribution.hpp) and [epochs](../architecture/epochs.md) for boundary semantics.

Rolling refits from retained trials; Frozen fits/loads once but **continues collecting** trials. Default per-class capacity0 means unlimited; default warmup20 per class. Failed refit retains the previous working model. Restored trials must match feature length; restored history is not counted as newly received. Loaded-model applicability warnings recur when arming because geometry can change after load; cross-subject transfer is explicit warning-bearing use, not silently certified generalization.
