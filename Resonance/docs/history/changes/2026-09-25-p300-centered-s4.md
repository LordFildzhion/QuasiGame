# MATLAB FisherDA_s4: centered default

Date: 2026-09-25. Current contract: [P300](../../components/p300.md).

Updated `W:/MATLAB/resonance_p300/FisherDA_s4.m` to accept an optional fourth argument, `doCenter`. Omitted or empty means true. Existing two- and three-argument calls now fit using each class's own centered samples and n−1 covariance denominator. Explicit false retains the original uncentered second moments divided by n. Omitted or empty `alpha` is 0.01. Centering accepts scalar logical or numeric 0/1; the centered branch requires at least two observations per class.

The mean difference on the right-hand side, 1% mean-diagonal regularization, weight shape, inverse-based solve, and absence of output normalization/bias remain unchanged. Centering does not subtract the means from the inference features. The new default has the same weight direction as the study's Mov1; it is not Mat2, which used n. Historical comparison results retain their original definitions.

```matlab
W = FisherDA_s4(T, N);                 % centered n-1, alpha=0.01
W = FisherDA_s4(T, N, alpha, true);    % centered, custom regularization
W = FisherDA_s4(T, N, alpha, false);   % original uncentered n calculation
```

After estimating a class mean, n−1 gives the usual unbiased sample covariance; n remains a valid maximum-likelihood convention. With equal class sizes, replacing n by n−1 multiplies the covariance sum and its proportional ridge by one common factor, so it only rescales the fitted weights. Unequal target/non-target sizes receive slightly different factors; their weight direction and occasional decisions can change. The difference shrinks as the class sizes grow. It is separate from the much larger conceptual change of centering.
