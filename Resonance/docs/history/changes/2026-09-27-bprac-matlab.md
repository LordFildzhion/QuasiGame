## Corrections and deliberate differences

- Unified little-endian legacy/HDF5 import, physical EEG units, recorded channel labels, authoritative block counts rather than allocated HDF5 extents. Malformed counters, gaps and incompatible metadata are not silently repaired.
- Static-condition labels follow old group 1=count / group 0=active and new cue marker 1/2; old `istarget` is not used to label movement. Epochs preserve event indices on rejection. Duration and measurement windows are checked.
- Continuous independent-channel transforms replace flattening channels into a single signal. Additive superlets match the supplied `aslt.m`; PSD/Hz and superlet power are labelled separately. CSP is optional, regularized and descriptive; physical maps and component traces are distinguished. Peak frequency is selected on each channel's actual grid.
- P300 MATLAB implementation covers stock Mov0 FIR/Fisher and current native SOS/count-pooled ridge Fisher. Filters run continuously before epoching. Native replay respects the recorded first processed EEG block, optical edge search and Movicom D7 ledger. Invalid/missing clock data cannot fall back silently to message timing.
- Whole-letter validation replaces random flash holdout. Both fitting and validation use complete letters. The legacy reference's final training letter lacks enough recorded FIR tail in both matrices: 13 unavailable features in 3×3 and 12 in 6×6 cause the entire final letter to be excluded. Existing `.ld` weights remain replayable to verify the historical outputs.
- P300 ERPs use a separate descriptive zero-phase branch, not the classifier feature data. Real time axes, per-class counts, baseline, peak windows and explicit units are returned. Intended typing text is optional; absent truth remains NaN/unscored. Alphabet decoding preserves spaces/backspaces and refuses fabricated mappings from corrupt metadata.
- Native model fitting is within-subject. Existing group/adapted models can be replayed; MATLAB group-prior fitting/adaptation is outside this delivery. Unsupported native FIR/digital-trigger models are rejected explicitly by this BPRAC-specific port.
