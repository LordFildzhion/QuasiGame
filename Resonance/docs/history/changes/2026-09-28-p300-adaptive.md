# Optional adaptive P300 Typing

Implemented and tested 2026-09-28. [Current service contract](../../components/p300.md#adaptive-typing) · [Study and report](../investigations/p300-adaptive-20260928.md).

## Behavior

Native Typing optionally stops before its configured cycle limit. Timings adds Adaptive cycling (off), Minimum evidence (2 scored cycles), and Lead threshold (1.5). Flash cycles remains the hard maximum and fixed training count. Parameters have tooltips; the count uses an in-box cycles unit. Pretraining is fixed, and only its subsequent ordinary Typing phase enables the rule. Jumbled/focus modes remain fixed; legacy MATLAB/SPEED cannot supply native cycle evidence and clearly refuses an explicitly requested adaptive ordinary-Typing setup.

`P300/adaptive.cpp` calculates a scale-invariant residual score-lead statistic. `LiveClassifier` reports evidence after complete, valid EEG cycles. QML checks at visible-cycle boundaries without inserting a scoring pause, removes only future unshown cycles and requests a result. Native code validates that request against evidence it actually generated for the active run/trial, and waits for all already-shown epochs. Results record presented/planned cycles, stop reason and triggering evidence. Invalid or missing EEG still fails normally.

Run metadata freezes policy/version/minimum/threshold/cap. Evidence and stop requests are recorded in the existing event stream; no extra Recorder stream selector is required. Native and BPRAC MATLAB importers recognize intentional early completion only with matching run/trial, enabled ordinary Typing, a prior decisive-evidence event and coherent complete-cycle counts. Unexplained truncation remains rejected. Existing native model schemas/weights, monitor defaults, venue presets, operator configuration and the prior ZIP snapshot are retained.
