`AVtest_nvx-training-0002.hdf5` contains seven complete test selections. Its recorded online output is **ФОЖЕГОД**, matching the supplied intended text: **7/7 (100%)**. ## Signal and optical timing

Learning/test sample counts are 143,748 / 97,025 (143.748 / 97.025 seconds at the nominal rate). All eight EEG columns contain only finite samples. After the initial ten seconds, continuously filtered channel standard deviations are 5.36–9.44 µV for learning and 4.88–9.34 µV for test. The raw O1 median is approximately 9.15 / 9.64 mV; this DC offset is removed by the causal high-pass and does not itself establish input saturation. These statistics are signal checks, not a formal artifact or physiological diagnosis.

All **667 learning and 422 test flashes** have an observed adjacent-finite-sample photodiode rising crossing, including the incomplete tails. Accepted epochs use 660 / 420 of these crossings. AUX1 contains 460 / 273 nonfinite samples elsewhere; the detector never bridges them and no required crossing was lost. No recording block gap exceeds three seconds. Reception timestamp boundaries vary and are not hardware sample-loss measurements.

Event-to-observed-photodiode delays have medians **49.13 / 48.66 ms**, 95th percentiles **55.50 / 55.33 ms**, and full ranges 39.10–59.38 / 39.05–63.00 ms. This includes display and acquisition timestamp behavior; it is not a standalone monitor latency measurement. Epochs use the measured photodiode onset, not the nominal software event plus this median.

## Replay correction and verification

The test file exposed a filter-start import error: the preceding EEG block's reception-based timestamps overlap the next block's first-sample time. The old importer trimmed that preceding block at `firstSampleNs`, introducing two samples that the live processor had never received. Offline onset indices were shifted by two samples; the largest first-letter score discrepancy was 0.192755252. Final letter decisions were unaffected. The learning file does not have this origin overlap, so its saved model is unchanged.

`P300/service.cpp` now emits the original EEG block timestamp for every timing mode. `recordingimport.cpp` starts at that block and validates its presence and nominal first-sample time. Older timestamp/analogue recordings resolve the exact full-block start when available. Missing or conflicting explicit origins are refused. Movicom retains its mapped-clock validation.

After the correction, all **420 online test scores match exactly**, with identical epoch sample indices and all 35 cumulative decisions. Independent continuous SciPy filtering and feature extraction agree within 2.10e−16 relative error for both recordings. A synthetic overlapping-block regression covers old and new origin formats plus missing/mismatched origin refusal.
