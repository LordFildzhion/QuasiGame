# Установка и запуск (Windows x64)

Архив содержит полную поставку Resonance, Native LSL, SPEED и QuasiGame. LSL подключается штатными средствами Resonance; отдельный LSL-сервис не нужен.

## Первый запуск

1. Распакуйте архив целиком на локальный NTFS-диск, например в `C:\EMGProject`. Не запускайте из ZIP или с виртуального диска.
2. Один раз выполните `Install.bat`. Установщик проверит Microsoft Visual C++ Redistributable x64 и Python 3.12, а также создаст отдельное окружение `Runtime/GameVenv` для игры и обработки сигналов.
3. Запускайте `Start_All.bat`. Он открывает SPEED и QuasiGame в отдельных процессах.
4. В Resonance подключите нативный LSL-поток и назначьте его полю Stream 1 SPEED. Выполните Prepare → Start. Первые 2 секунды держите обе руки расслабленными — детектор оценивает шум покоя.

## Настройки

- `Resonance/params/speed_configurator.txt`: источник, частота, каналы ЭМГ, единицы измерения, фильтры, параметры детектора сокращений и настройки Bridge. SPEED формирует два разреженных выхода: `left_contraction_event` и `right_contraction_event`; между сокращениями значения равны нулю.
- `Resonance/params/speed_two_hands.json`: профиль SPEED с Native LSL. Если источник имеет другое имя, выберите его вручную в Stream 1.
- `Game/Config.txt`: игровые параметры, длительность рывка, выбранная рука и настройки клавиатурного теста. UDP-порт относится к `Bridge`, а не к игровому движку.
- `Bridge/`: отдельный UDP-адаптер между SPEED и публичным `Game/API/gameapi.py`.

## Проверка без датчика

Откройте в VS Code именно корень проекта (папку, где находятся `Game`, `Bridge`, `Integration`, `Resonance` и `Start_All.bat`). Выберите конфигурацию `QuasiGame — Keyboard Test` и нажмите F5. Один переход Space из отпущенного состояния в нажатое создаёт одно тестовое сокращение; удержание клавиши не повторяет его.

Для запуска одной игры из командной строки используйте `run_game.bat --keyboard`. Для запуска игры, которая принимает события от уже работающего SPEED, используйте `run_game.bat`.

**Важно:** окружение Resonance и игровое Python-окружение изолированы. Не запускайте игру из CMD после вызова `Resonance/env.bat` без очистки `PYTHONHOME` и `PYTHONPATH`. Полная проверка LSL и физического датчика выполняется только на Windows с подключённым устройством.
