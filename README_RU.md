# Resonance + QuasiGame v12 — Native LSL, двухканальная ЭМГ и событийное управление

Windows x64. После распаковки запустите `Install.bat` один раз. Для полной системы используйте `Start_All.bat`: он открывает SPEED и отдельный процесс игры. Источник Native LSL подключается штатными средствами Resonance; затем выберите входной поток в SPEED и нажмите Prepare → Start.

## Новая логика управления

Теперь используется **событийная модель**: одно подтверждённое сокращение мышцы создаёт одно событие с нормированной интенсивностью `0..1`. Событие вызывает короткий рывок удочки. Значение не пересылается в игру 20 раз в секунду как непрерывный уровень. Слабое сокращение даёт более сильный игровой рывок (`hook_power = 1 - emg_strength`).

Первые 2 секунды после Prepare/Start интерпретатор оценивает шум покоя, поэтому руки и электроды должны оставаться неподвижными. Параметры чувствительности находятся в `[event_detection]` файла `Resonance/params/speed_configurator.txt`. Начальная настройка использует порог `4.0 sigma` и минимум `20 мс`: это консервативный компромисс против ложных срабатываний на шуме; для слабых микро-сокращений порог можно осторожно снижать после проверки покоя.

## Архитектура

- `Game/` — отдельный игровой движок. Он принимает события только через `Game/API/gameapi.py`; сетевого и LSL-кода в движке нет.
- `Bridge/` — отдельный транспортный адаптер и владелец UDP-настроек. Он пересылает события между SPEED и `GameAPI` через локальный UDP. Конфигурация игрового движка не содержит UDP-портов.
- `Integration/run_game.py` — точка сборки игры и Bridge.
- `Resonance/mulines/` — LSL/SPEED и обработка ЭМГ, включая обнаружение сокращений.

Сохранены два выхода SPEED: `left_contraction_event` и `right_contraction_event`. Их значения равны нулю между событиями и содержат импульс нормированной интенсивности в точке обнаружения сокращения.

## Тестирование

- Только клавиатура: `run_game.bat --keyboard` или VS Code → `QuasiGame — Keyboard Test` → F5.
- Запуск игры для работы с запущенным SPEED: `run_game.bat` или VS Code → `QuasiGame — Resonance / LSL` → F5.
- Полный запуск: `Start_All.bat`.

В `Game/README_EMG_RU.md` описаны настройки порога, гистерезиса и времени подтверждения.

## Ограничение чувствительности

Встроенный старый отчёт `Resonance/calib/emg_baseline.json` помечает оба канала `low_quality`: в нём активность задания не отделяется от фона покоя. Поэтому новая логика может искать слабые изменения относительно автоматически оценённого шума, но подтвердить распознавание микро-сокращений можно только на новой записи с текущими электродами и датчиком. Если амплитуда сокращения неотличима от шума, программная обработка сама по себе не восстановит её.
